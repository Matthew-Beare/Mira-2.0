## Why this packet

MIRA already has ordinary-language intake, feature/dependency grounding, candidate/review evidence, activation/rollback contracts, provider-neutral runtime routing, a durable compute-job control plane, and local-compute policy concepts. The missing user-value path is execution. Continuing to add review-only structures would increase code volume without letting Studio actually implement anything.

This packet therefore builds the smallest safe executable worker that can later plug into the existing compute fabric. It is intentionally concrete: real Git, real subprocess test execution, real HTTP to a loopback model endpoint, real changed files, and machine-readable evidence.

## Safety and authority

The worker may create only an isolated worktree/branch from an exact recorded base SHA. The controller, not the model, owns the repository, base SHA, branch, editable paths, tests, endpoint, model, budgets and stopping rules. Model output is data only.

The worker MUST NOT merge, push, publish, activate, install, modify credentials, invoke arbitrary model-supplied commands, reach a non-loopback model endpoint, mutate the source checkout, or broaden the editable-path allowlist.

Symlinks/path traversal and changes outside the allowlist fail closed. `shell=False` is mandatory for test execution. A successful candidate remains staged for the existing Studio review/approval machinery.

## Intended deliverables

- `ops/studio_local_worker.py`: Windows/Linux-compatible Python stdlib executable worker.
- `tests/test_studio_local_worker.py`: end-to-end and adversarial tests using temporary Git repositories and a fake loopback OpenAI-compatible server.
- bounded documentation/checkpoint evidence in this packet and `CURRENT_WORK.md`.

## Acceptance

1. Exact-base isolated branch/worktree creation is proven with real Git in tests.
2. Strict loopback-only model endpoint validation is proven.
3. Strict model response schema and editable-path enforcement are proven.
4. Fixed argv tests run with `shell=False`, timeout and stdout/stderr capture.
5. Repair is bounded by rounds and wall clock, with deterministic stop reasons for pass, malformed response, stagnation, regression and budget exhaustion.
6. Per-round evidence binds model response, changed paths, candidate tree/commit identity and test result.
7. Source checkout/base branch remains unchanged after execution.
8. Full MIRA CI remains green.
9. Merge and post-merge verification remain separate from worker success.
