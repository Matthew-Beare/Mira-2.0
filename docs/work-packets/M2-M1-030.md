## Objective

Implement the capability-based model profile and benchmark evidence seam required by the optional compute fabric. Public product logic can evaluate whether a model profile satisfies explicit task requirements without hard-coding a model family, machine, accelerator, path, provider endpoint, benchmark score or quality threshold.

This packet is profile/evidence evaluation only. It does not install a model, load weights, execute inference, benchmark a live worker, persist private deployment binding, alter worker routing or claim a live model capability.

## Implemented behavior

- `mira/model_profiles.py` defines sanitizable model profiles using logical profile/runtime/artifact IDs, artifact SHA-256, sorted generic capabilities and explicit context/output capacities.
- Benchmark observations carry exact benchmark/version/capability/metric identity, finite value/unit, UTC observation time, positive sample count, evidence kind and provenance digest.
- Benchmark requirements carry explicit comparator, threshold, unit, freshness and allowed evidence kinds. Public code supplies no benchmark thresholds.
- Selection requests carry explicit capability/context/output minima, benchmark requirements and optional ordered preferred profile IDs.
- Missing capability/capacity/evidence, stale/future evidence, unit mismatch, disallowed evidence kind, duplicate matching observations and threshold failure all fail closed.
- Exact `at_least` and `at_most` threshold equality is accepted.
- Extra unrequested benchmark observations do not gain selection authority.
- Eligible preferred profiles win by explicit policy order; otherwise stable logical profile-ID ordering is only a deterministic tie-break, not an inferred quality score.
- Result ordering is deterministic and contains no private deployment or execution material.
