## Objective

Define how a worker proves an already-authenticated identity to MIRA, advertises generic capabilities and current execution state, and is projected into the existing runtime router without exposing private deployment details or manufacturing provider authorization evidence.

## Acceptance criteria

1. A worker identity proof is opaque and secret-free: stable principal ID, verification state and UTC verification timestamp only.
2. Unverified, revoked or otherwise non-verified identity proof cannot produce a routable worker advertisement.
3. Worker advertisements contain only generic lane/runtime identity, runtime kind, generic runtime capabilities, health, availability, lock, priority/load/cost ranks, policy and heartbeat time.
4. Advertisements contain no hostname, IP address, credential, token, shell endpoint, model path, device serial, MAC address or private hardware identity.
5. The advertisement validates heartbeat and identity timestamps as UTC and rejects future heartbeat evidence relative to projection time.
6. Heartbeat freshness is explicit. A stale worker projects fail-closed as unavailable/unknown rather than remaining eligible because its last state happened to be healthy.
7. Projection consumes an externally supplied `ProviderCapabilitySnapshot`; it does not invent provider authorization/read/write/readback evidence.
8. The supplied provider capability service identity must match the worker advertisement service identity.
9. Worker policy is converted into the existing `RuntimePolicy`; local-compute OFF and interactive lock retain precedence in the existing router.
10. Candidate generation is deterministic and compatible with the existing `route_runtime` contract.
11. Tests cover verified/unverified identity, stale heartbeat, future heartbeat, capability/service mismatch, policy precedence, secret-free shape, and successful selection of a fresh eligible worker.
12. Exact-head CI must pass before merge. No durable registry, live worker, network transport, WOL/shutdown, local model or private deployment claim is made.
