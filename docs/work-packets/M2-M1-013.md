8. **Scenarios/interventions:** reserve catch-up, spending-cut correction, career-transition thresholds and a bounded retirement lever are implemented. Blank match-preserving contribution input cannot activate a full retirement cut.

10. **Trends:** mileage vs required, actual debt vs target, and retirement-contribution charts are preserved on a separate Trends surface so the executive Dashboard stays phone-readable.
11. **Brief integration:** the existing enabled 2:45 AM America/New_York brief owns the canonical daily Financial Escape snapshot/refresh/readback contract. The existing PM brief performs a lightweight same-day refresh/readback and may update the same day's snapshot in place but must not create a duplicate history row.
