# Manual Evidence Audit Gate

Full-manual evidence requires a substantive manufacturer owner/user, instruction/operation, or service manual applicable to the verified exact model or an explicitly documented model family.

Setup guides, quick-start guides, installation leaflets, product/support pages, and retailer PDFs are secondary evidence only. They do not satisfy the full-manual requirement.

Previously linked manuals are not grandfathered. Re-verify document type and model applicability before treating any prior link as full-manual evidence.

Current bounded audit results (2026-09-24):
- WRX factory service manual: passes as service-manual evidence.
- FL5 service-reference manual: passes as service-manual evidence with the existing applicability warning.
- Logitech C920s setup guide: secondary setup evidence only; not a full manual.
- VEVOR HTJ-1322 manufacturer User manual-en PDF: passes as full user-manual evidence on the exact-product page.
- Eastwood 31158: unresolved; no substitute promoted.
- LAUNCH CRP129E V2.0: unresolved; no different-family manual promoted.

This gate refines existing ASSET/IDENT/EVID/INV evidence semantics and does not create a parallel inventory model.
